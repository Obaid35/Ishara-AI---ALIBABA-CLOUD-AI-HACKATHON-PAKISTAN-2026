**Healthcare + Pakistan + trust**

## Usage
Use `#017A3A` for:
- logo/brand;
- active mode;
- primary Speak button;
- selected doctor phrase;
- focus/accent states.

Do not fill the entire UI with dark green. Keep roughly 70–80% white/light neutral.

## Camera area
A dark neutral video container is acceptable, e.g. `#101828`, because it separates the live camera naturally.

## Status colors

### Communication screen
- recognized: green + check/text;
- repeat / ambiguous match: amber + icon/text;
- not recognized / error: red + icon/text.

The two unknown states are deliberately different colours. Amber means the system nearly had it; red means it did not.

### Admin status pills
- `reliable` / `enabled` / `granted`: success green;
- `testing` / `experimenting` / `requested`: info blue;
- `draft` / `candidate` / `unknown`: neutral grey;
- `weak` / stale audio / permission gap: warning amber;
- `dropped` / `rejected` / `denied`: error red.

Never rely on color alone — every status carries text, and icons where space allows.

## Avoid
- purple AI gradients;
- neon green;
- full dark theme;
- low-contrast green-on-white text;
- excessive shadows.
